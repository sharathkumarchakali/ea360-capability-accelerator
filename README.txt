EA360 ChatGPT Replica
======================

Open index.html in any modern browser.

Includes:
- Responsive desktop/mobile navigation
- All EA360 sidebar menu items
- Executive dashboard
- Assessment, Findings, Evidence, Recommendations, Roadmap
- Architecture Reviews, Decisions, Exceptions, Standards
- People & Skills, KPIs, Executive Report
- Organisation, Assessment Model, Settings
- Working active states
- Search modal
- Notifications/profile popovers
- Demo organisation selector
- Illustrative/demo data only

This is a self-contained front-end prototype with no external dependencies.
